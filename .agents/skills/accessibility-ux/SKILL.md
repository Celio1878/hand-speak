# Accessibility & Inclusive UX Skill

Esta skill guia o desenvolvimento de interfaces inclusivas para pessoas surdas e com deficiências de fala.

## 1. Princípios de Design Visual para Pessoas Surdas
- **Centralidade Visual**: Como a audição não está disponível, 100% dos estados do sistema devem ser perceptíveis pelos olhos (ícones animados, bordas luminosas, anéis circulares de progresso, crachás de status).
- **Tipografia Escalonada**: A transcrição deve usar tamanho generoso (`text-2xl` a `text-4xl`), fonte limpa (Inter) e alto contraste contra o fundo.
- **Diferenciação Cromática nas Mãos**:
  - Mão Direita: Traçado Ciano / Esmeralda (`#00e5ff` / `#10b981`).
  - Mão Esquerda: Traçado Âmbar / Laranja (`#f59e0b` / `#f97316`).

## 2. Padrões Freemium Respeitosos
- O modal Freemium NUNCA deve bloquear a comunicação essencial do usuário: o motor local de Libras, a soletração e a síntese de voz nativa permanecem 100% funcionais mesmo com cota de IA zerada.
- O banner de upgrade deve ser informativo, oferecendo a opção transparente de usar a chave pessoal gratuita do Google AI Studio (BYOK) para quem não puder assinar o plano Pro.
